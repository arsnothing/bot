# سامانه ثبت گزارش

نسخه بازطراحی‌شده برای استفاده موبایلی و WebView بات.

## مسیر ثبت گزارش

صفحه اصلی → موضوع گزارش → در صورت نیاز انتخاب زیرنوع → فرم اطلاعات → زمان → مکان → تصویر → ثبت نهایی

موضوع‌ها:
- افراد
- املاک
- اشیاء
- رویداد
- نهاد و سازمان

برای «اشیاء» ابتدا نوع شیء انتخاب می‌شود:
- بسته مشکوک
- خودرو مشکوک
- پرنده
- آنتن استارلینک

برای «رویداد» ابتدا نوع رویداد انتخاب می‌شود:
- تجمع، تحصن یا اغتشاش
- انفجار یا آتش‌سوزی

در مرحله «فرم»، اطلاعات هر نوع گزارش به چند بخش کوتاه تقسیم می‌شود. کاربر با «مرحله بعد» و «مرحله قبل» میان بخش‌ها جابه‌جا می‌شود و اطلاعات واردشده در هر بخش حفظ می‌شود.

زمان و مکان در صفحه‌های جداگانه ثبت می‌شوند و می‌توان آن‌ها را ناشناخته گذاشت. مکان از موقعیت فعلی، انتخاب روی نقشه یا ورود دستی استان/شهر/آدرس پشتیبانی می‌کند.

ضمیمه فقط تصویر است و امکان انتخاب چند تصویر وجود دارد.

اطلاعات گزارش در `data/reports.json` ذخیره می‌شود.
